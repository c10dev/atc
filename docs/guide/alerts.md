# 알림 받기

화면을 계속 보지 않아도 atc가 바뀐 것을 알려 줍니다. atc 탭이 열려 있으면(뒤에 있어도) 브라우저 알림과 소리로 알립니다. **둘 다 기본은 꺼짐**이고, 이 브라우저에만 저장됩니다. 켜는 곳은 왼쪽 위 로고를 눌러 여는 설정의 **알림** 탭입니다.

밖으로 나가는 것은 없습니다. 푸시 서비스, 이메일, 휴대폰은 쓰지 않고, 알림 글은 화면에 이미 있는 문구뿐입니다. atc는 팀 세션에 메시지를 보내지 않습니다. 알림은 SUPERVISOR인 당신에게만 알립니다.

## 무엇이 알림이 되나

atc가 이미 찾아내는 것을 알릴 뿐, 새로 찾아내지는 않습니다. 같은 일에는 늘 같은 열쇠(key)가 붙고, 열쇠마다 한 번만 알립니다.

| 종류 | 예 | 소리 |
|---|---|---|
| AIRCRAFT health | LIMIT(끊김), `RESUME 필요`, `STALLED`, NETWORK | 등급에 따름 |
| ALERT | CONTACT가 끊긴 STAND, STAND 충돌, 머지됐는데 main에 안 닿음 | 등급에 따름 |
| FLIGHT FOLLOWING | CAPTAIN이 SUPERVISOR의 go를 기다림, UNABLE, LAUNCH 실패 | 등급에 따름 |
| SUPERVISOR 대기 | 도구 승인을 기다리는 PENDING, 판정할 DISPATCH 제안, HUMAN CHECK, 그리고 SCHEDULE이 **approval 모드**일 때 판정을 기다리는 SCHEDULE 작업(초안·동의·반대 상태). shadow 모드의 SCHEDULE은 게이트 판정이라 알리지 않습니다 | CALL |
| PR 착륙 가능 | CLEARED TO LAND가 된 PR | 조용함 |
| RTS 결과 | RETURN TO SERVICE 성공·거절·ROLLBACK·실패 | 성공은 DONE, 실패·ROLLBACK은 WARNING, 거절은 CAUTION |
| CONTROL RECYCLE 대기 | 컨텍스트가 CAP을 넘었는데 `waitAlertMin`(기본 60분) 넘게 재시작하지 못함. 막는 것이 글에 적힌다 | CAUTION. 기다리거나, 괜찮으면 FLEET의 CONTROL SESSIONS에서 손으로 STOP·LAUNCH |
| REPOSITION | atc가 AIRCRAFT를 자동으로 옮김, 옮기기 실패, auto가 flapping으로 approval이 됨(SUPERVISOR가 승인한 성공은 알리지 않음) | 자동 옮김·되돌림은 ADVISORY, 실패는 CAUTION(LAUNCH만 실패하면 base는 바뀐 채) |
| FOLLOW | [따라가는 번들](follow.md)의 줄: **풀 수 있음(READY)**, 줄의 제안이 **승인 대기**(그 제안은 "SUPERVISOR 대기"로 한 번 더 알리지 않고 이 종류로만), **막힘**(FOLLOW 탭이 줄에 붙인 `막힘` 표시 전부: 제안 없이 Todo 30분, 승인했는데 발송 없음 10분, 착륙했는데 배포 없음 15분, READBACK 없음, 그리고 FLIGHT FOLLOWING의 지연·불일치), **GO AROUND·ROLLBACK·되돌려진 PR**(실패), 착륙(ON)과 배포(IN)의 기록 | 풀 수 있음·승인 대기는 CALL, 막힘은 CAUTION, 실패는 WARNING, 착륙·배포는 조용함(LOG) |
| CONTROL RECYCLE 결과 | atc가 관제 세션을 재시작함(`on`일 때만. shadow의 기록은 알리지 않음) | 성공은 ADVISORY, 실패는 CAUTION(LAUNCH만 실패했으면 세션이 멈춘 채. STOP을 확인하지 못했을 때도 LAUNCH를 시도하고, 거절되면 세션이 내려갔을 수 있다고 알린다) |

알림에는 AIRCRAFT, FLIGHT, 한 줄 문구와 **다음 한 걸음**이 들어 있습니다. 알림을 누르면 atc 탭이 앞으로 오고 그 항목이 있는 탭이 열립니다.

## 브라우저 알림 켜기

1. 설정 → **알림** → NOTIFY를 **켜기**로 누릅니다. 브라우저가 권한을 물으면 허용합니다.
2. 받을 종류를 고릅니다(기본은 모두).

atc를 처음 연 브라우저는 지금 있는 항목을 기준선으로만 삼고 알리지 않습니다. 그 뒤에 새로 생긴 것만 알립니다. 서버가 재시작(RTS)되어 다시 연결될 때도 그동안 새로 생긴 것만 알립니다. 사라졌다가 10분 안에 돌아온 같은 항목은 다시 알리지 않습니다.

탭을 여러 개 열어 두어도 알림은 한 번만 뜹니다.

권한이 거부됐거나 알림을 껐을 때는 **탭 제목의 숫자**와 헤더의 **BELL** 목록이 대신합니다. BELL 숫자는 조치가 필요한 것(WARNING, CAUTION, SUPERVISOR 대기) 가운데 아직 확인하지 않은 수이고, BELL을 누르면 목록이 열려 항목을 눌러 그 탭으로 가거나 **ACK**로 확인할 수 있습니다.

## ANNUNCIATOR 창에서는

Mac 메뉴 막대 앱 ANNUNCIATOR 안에서 atc 화면을 열면(창 user-agent 끝에 `ANNUNCIATOR/<버전>`), 알림 톤·음성 콜아웃·브라우저 알림은 **앱이** 냅니다. 이 화면은 아무것도 울리지 않고 알림을 띄우지 않으며, 헤더의 `🔇 소리 잠김` 칩과 놓친 알림 다시 울리기도 없습니다. 설정 창의 알림 탭에는 컨트롤 대신 "알림 소리와 음성은 ANNUNCIATOR가 냅니다 (앱 설정)" 한 줄만 있습니다. BELL 목록과 RADIO 탭(듣기 포함)은 그대로입니다. 브라우저에 저장된 알림 설정은 바꾸지 않으므로, 같은 저장소를 보통 브라우저에서 열면 전과 똑같이 동작합니다.

## 소리 켜기

소리는 알림과 따로 켭니다. 알림 권한이 없어도 울립니다. **켜는 클릭**이 브라우저의 소리 잠금을 풀고, 확인용으로 CAUTION 소리가 한 번 납니다. 나중에 브라우저가 소리를 멈추면(탭이 오래 뒤에 있었거나 Safari가 오디오를 중단한 경우) 두 가지가 일어납니다.

- **먼저 스스로 풀어 봅니다.** 소리를 내야 할 때, 그리고 탭이 다시 보이거나 창이 초점을 받을 때 atc가 브라우저에 오디오를 다시 켜 달라고 요청합니다. 브라우저가 받아 주면 그대로 울립니다.
- **그래도 안 되면 잠금을 보여 줍니다.** 소리가 켜져 있는데 잠겨 있으면 헤더에 `🔇 소리 잠김 — 클릭하면 켜짐` 칩이 계속 떠 있고(설정과 BELL 목록에는 `소리 꺼짐 — 눌러서 켜기`), 페이지의 **아무 클릭이나 키 입력** 한 번이 잠금을 풉니다(칩을 눌러도 됩니다). 풀리면 칩이 사라집니다.
- **잠겨 있는 동안 온 것은 놓치지 않습니다.** 그동안 울렸어야 할 WARNING과 CALL은 "놓침"으로 남고, 탭 제목 앞에 `🔇1`처럼 개수가 붙습니다. 잠금이 풀리면 그중 아직 알림 목록에 있는 것 **가장 높은 하나**만 한 번 울립니다(음성이 켜져 있으면 음성도). 이미 사라졌으면 울리지 않고, 조용한 시간이면 그때도 울리지 않습니다.

| 소리 | 언제 | 모양 |
|---|---|---|
| WARNING | WARNING 등급 | 빠른 두 음 펄스, **확인(ACK)할 때까지 되풀이** |
| CAUTION | CAUTION 등급 | 부드러운 두 음 차임, 한 번 |
| CALL | SUPERVISOR를 기다리는 새 항목 | 짧은 두 음쌍(SELCAL 같은 모양), 한 번 |
| DONE | RTS 결과가 성공(기본 꺼짐) | 낮은 음 하나 |

WARNING과 CALL은 톤 뒤에 짧은 영어 음성 콜아웃도 읽을 수 있습니다(기본 꺼짐, 로컬 엔진이 필요합니다: [음성 콜아웃](voice.md)). ADVISORY는 조용합니다. 소리마다 켜고 끌 수 있고, 설정에서 미리 들어 볼 수 있습니다. 음량과 **조용한 시간**(현지, 자정을 넘겨도 됨)도 정합니다. 조용한 시간에는 알림 글은 뜨지만 소리는 나지 않습니다.

- WARNING의 되풀이는 알림을 누르거나, BELL에서 ACK하거나, 그 항목이 있는 탭을 다시 보면 멈춥니다. 다른 탭에서 확인해도 멈춥니다.
- 소리는 한 번에 하나만 납니다. 2초 안에 함께 온 것은 가장 높은 등급 소리 하나입니다. 울리는 소리보다 높은 등급이 오면 끊고 울립니다.
- 같은 항목은 10분 안에 다시 울리지 않습니다.
- 소리는 알림을 띄운 탭에서만 납니다. 그 탭은 소리를 켠 클릭을 받은 탭이어야 하므로, 자주 쓰는 탭에서 켜 두세요.
- 서버는 소리를 내지 않습니다. 소리는 이 브라우저에서만 납니다.
