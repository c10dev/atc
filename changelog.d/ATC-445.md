### Changed
- The control sessions moved into a folding CONTROL panel at the foot of the screen column (ATC-445, [docs/layout.md](docs/layout.md) "Z5 as built"). The folded one-line header replaces the header CONTROL strip: `CONTROL` with the number of sessions that need the SUPERVISOR, then one chip per session with a dot and a word (`OK`, `WORKING`, `NEEDS`, `LATE`, `DOWN`), DOWN and NEEDS first. At 860 px and narrower only the NEEDS, DOWN and LATE chips show, and `OK n` for the rest.
  - Opened, it holds the CONTROL SESSIONS table (LAUNCH, STOP, ACCOUNT) and the selected session's recent radio. It opens from its arrow, from a chip or with Ctrl+\`, never by itself; the height is dragged or set with Arrow Up / Down and remembered in this browser; at 860 px and narrower it is a sheet from the bottom.
  - FLEET no longer has the CONTROL SESSIONS group. `#fleet/control` (settings link, server alerts) opens the panel; `#control` does too.
