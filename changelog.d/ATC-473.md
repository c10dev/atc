### Changed
- A STAND-free FLIGHT (SURVEY, CHECK) never has a worktree, so the "진행 중인데 워크트리가 없음" alert is no longer raised for it; FLIGHTs that need a STAND keep it. When such a FLIGHT has ARRIVED in the LOGBOOK but its Linear issue is still In Progress, HOME's to-do list shows one `ARRIVED` item (FLIGHT, AIRCRAFT, arrival time, the ARRIVED note, result link and issue link) with a `Done…` action. After one confirmation on the page it moves that issue to the team's Done through the existing SUPERVISOR-only `POST /api/flight/:key/state` (`{from, toType: "completed"}`). The server allows that move only for a STAND-free FLIGHT with an ARRIVED entry that is `started`; every other started → completed move stays refused, and the server still never writes Linear on its own (ATC-473).
