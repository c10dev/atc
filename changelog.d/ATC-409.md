### Changed
- Reduced motion: when the operating system asks for reduced motion, atc stops its motion (RADAR sweep, Night Sky stars, flaps, GLOBE movement) whatever the saved `motion` setting says, and follows a change of the OS setting without a reload (ATC-409, [docs/design-language.md](docs/design-language.md) principle 10).
  - Before, the OS setting only chose the default the first time, and a saved `motion: on` kept everything moving.
  - The settings window says when the OS request is in force. When the OS does not ask, the saved setting decides as before; the default for a new browser is on.
