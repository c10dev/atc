### Fixed
- A state change atc itself writes to Linear (a state button, RELEASE fire, RELEASE discard) now shows at once. The server's cached Linear tickets take the new state as soon as the write succeeds, so a fired or discarded FLIGHT leaves the RELEASE lists on the click instead of staying up to two minutes with a live fire button. A Linear fetch that started before the write cannot put the old state back; once a fetch that started after the write lands, Linear's own answer wins. A failed write changes nothing.
