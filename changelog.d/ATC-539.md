### Added
- WARM START (ATC-539): after a restart the screen shows the last known snapshot at once instead of missing PRs for about 90 s ([docs/warm-start.md](docs/warm-start.md)). The server saves a warm snapshot to the new file `warm-snapshot.json` in the state folder (atomic, at most once a minute). On boot a file younger than `maxAgeMin` (default 10) is served by `/api/snapshot` and the SSE stream marked `restored` with its age, and the screen shows one line until the first live warm snapshot replaces it. Display only: DISPATCH, AUTOLAND, MCC, alerts, events and the FLIGHT RECORDER read live data only. A missing, corrupt or too-old file is a normal cold start, and deleting it is always safe. Settings → OPERATIONS → WARM START (default on, SUPERVISOR only) turns it off; there is no misfire counter because nothing acts on the data.
