### Added
- Settings → OPERATIONS → DUTY has a **DUTY L1** switch (`duty.json` `l1`, ATC-349). Turning it on is a ⚠ mode with the confirm step; it is written only through `PUT /api/settings` from this screen (403 without an `Origin`; no `atcctl` command, no control-session route). Other `duty.json` keys are kept, the default stays off, and L1 has effect only while DUTY is on.
