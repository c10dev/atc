### Changed
- Fewer merge conflicts between parallel PRs (ATC-64, [changelog.d/README.md](changelog.d/README.md)). On 2026-09-28 most conflicts were on `CHANGELOG.md` / `CHANGELOG.ko.md` and on design-doc status tables (`docs/fuel.md` section 8).
  - CHANGELOG fragments: a PR no longer edits `CHANGELOG.md` / `CHANGELOG.ko.md`. It adds `changelog.d/ATC-n.md` and `ATC-n.ko.md` with its entries under `### Added`, `### Changed` and so on. `node server/changelog-fold.ts` folds every pair into `[Unreleased]` of both files, on top of the first section with the same name (a missing section is created in Keep a Changelog order), and deletes them. It is idempotent, leaves existing lines and released versions where they are, and changes nothing if a fragment has no pair or a wrong format (`--check` only checks). `npm test` checks the repository's fragments on every PR.

Team PRs describe what they built in an unnumbered section of their own (`### F7 as built (ATC-57)`) right after the section about the feature.
