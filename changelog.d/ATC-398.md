### Changed
- DISPATCH no longer sends a FLIGHT that has a `K3` line in `## K effects` but would launch without a classifier allow entry (ATC-398, [docs/autonomy.md](docs/autonomy.md) C9).
  - A line that does not parse is held as "not a declaration"; a release that is not from the RELEASE screen or DUTY chat is held as "release on the screen". The reason and the fix show in the DISPATCH exclusion reason and a HOME alert.
  - The RELEASE screen shows, before the click, whether a FLIGHT's K3 declaration parses and whether the release grants the allow, plus the K3 HOLD state and its misfire counter (nuisance, miss). The off switch `k3Hold` (default on) is in the settings window only.
  - Work-order rules: each K3 effect is one `K3[<label>]: … | files: …` line, and a K3 work order is released on the screen or in DUTY chat, never attested by a session.
