### Changed
- The VERIFY GATE and BROWSER GATE CLI tests no longer set a floor under `npm test` time: the tests inside each file run in parallel, queued runs poll every 50 ms in tests, and the held slots are released by a file instead of a timer. Behavior and production defaults are unchanged; the CLIs only gained test knobs `ATC_GATE_POLL_MS`, `ATC_GATE_WAIT_LIMIT_MS` and `ATC_BROWSER_WAIT_LIMIT_MS` ([docs/verify-gate.md](docs/verify-gate.md)).
