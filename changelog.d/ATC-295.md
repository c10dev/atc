### Added
- The rules-drift hook is wired into atc's own sessions (`.claude/settings.json`: `SessionStart` start, `UserPromptSubmit` and `PostToolUse` check, `--ref origin/main`). A running AIRCRAFT now gets the unified diff on its next turn when `CLAUDE.md`, `docs/design-language.md` or `.claude/skills/atc-task/SKILL.md` changes, so the FLEET RULES line has something to report for atc. The hook never blocks (it exits 0 on any error and the command ends with `; exit 0`) (ATC-295).
