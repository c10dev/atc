### Changed
- MCC INSPECTION runs in a fresh context (ATC-135, [docs/mcc.md](docs/mcc.md) 8.2). A read-only `inspector` sub-agent (Opus, `mcc/.claude/agents/inspector.md`) reads each PR packet and returns the verdict block; the long-lived MCC session only orders the work and copies the verdict into `mcc inspect` / `mcc escalate`, and no longer reads a packet or a diff.
  - Guards: `mcc/inspector-guard.mjs` lets the inspector run only `mcc packet <PR>` and `gh pr diff <PR> --repo …`; `mcc/agent-guard.mjs` lets MCC call `inspector` and no other sub-agent. The Bash guard, the model check (`ATC_MCC_MODEL`), L1–L8 and the tiers are unchanged.
  - Context cap: above 150k tokens `mcc/context-cap.mjs` (a `UserPromptSubmit` hook) makes MCC ask the SUPERVISOR in its log line to STOP and LAUNCH it. MCC doesn't restart itself.
  - `mcc/packet-size.mjs` and `mcc/cost-report.mjs` measure packet size and MCC's cost per call, per hour and per inspected PR (before/after table in docs/mcc.md).
