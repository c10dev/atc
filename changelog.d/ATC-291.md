### Changed
- GLOBE: the default location is now the principal city of the browser's time zone (e.g. `Asia/Seoul` → 37.6°N 127.0°E) instead of latitude 0, and each non-home AIRPORT sits on a real large airport near the hub (12°–45°), so every point is on land; hovering an AIRPORT shows the airport's IATA code. Typed coordinates, geolocation and dragged AIRPORTs still win, and nothing is sent to the server (ATC-291, [docs/globe.md](docs/globe.md) "Land placement as built").
