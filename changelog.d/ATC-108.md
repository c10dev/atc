### Added
- SQUELCH S2 (ATC-108, [docs/squelch.md](docs/squelch.md) "S2 as built"). `controller/squelch.mjs <role>` is a fail-open `UserPromptSubmit` hook script: only a prompt that is exactly `/tick` is checked, with `POST /api/squelch/<role>` and a 3 s timeout, and the tick is dropped (`{"decision":"block","reason":"SQUELCH QUIET since 03:03Z (4)"}`) only when the server answers `open: false`. Anything else (another prompt, an error, a timeout) exits 0 with no output. `atcctl squelch <role>` prints the same decision as `OPEN <reason>` or `QUIET since HH:MM (n)`. No folder's settings call the hook yet (S3), so nothing changes for the control sessions. New [`controller/README.md`](controller/README.md).
