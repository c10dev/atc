### Fixed
- Review findings no longer get lost when the server restarts before TOWER's next tick (ATC-270). Findings on the current head of an APPROACH PR (MCC INSPECTION, the landing review, Codex, a carried review) are now a state-derived `FIX` item in `landingQueue[].fix` (`send`, `sent`, `supervisor`), so a `reset: true` pass still sends it and a head already sent is not sent again.

### Added
- A `FIX` CLEARANCE type, an instruction to act (W/U: `READBACK`, fix, push, or `UNABLE`) instead of an `INFO`. Its text keeps P0 and P1 lines in full and gives P2 as a count plus the PR link. `atcctl issue <session> FIX …`; the TOWER manual, tick skill, root `CLAUDE.md` and the `atc-task` skill cover the team side.

### Changed
- The APPROACH INFO is decided from state too (`landingQueue[].info`, compared with the last INFO sent for the PR), so a restart neither drops a new block nor resends an old one. It no longer carries review findings.
