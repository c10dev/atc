### Changed
- RELEASE draws its candidates, the Todo issues not yet released and the recent releases as one-line rows on the shared `TodoRow` (state tag, FLIGHT, title, priority, button), with the shared section heading, chip/tag and `.btn`. A `K` tag marks a declared K effect, and a problem (no priority, an unreadable K3 line, content changed after release) is said after the title. Pressing a row opens what the line does not say: the K effects in full, the K3 state, the parent issue, `after` order, same-file overlap, FLIGHT link and discard. The tree of groups is gone; waiting and started issues sit in a folded `대기·진행 중` section. The screen is a centred 880 px reading column with no coloured block in a normal state (ATC-423).
- The RELEASE sidebar is a section index (후보, Todo 발권 전, 최근 발권) with counts; choosing one scrolls to it (`#release/<section>`). It no longer repeats the READY list. The rail badge is unchanged (ATC-423, [docs/layout.md](docs/layout.md) "Z2 as built").
