### Fixed
- An AIRCRAFT whose background session ended by an idle retire or an atc STOP is no longer shown as RESTARTING an hour later. RESTARTING now starts at the last timestamped line of the conversation (retire appends untimestamped lines that moved the file time), and background sessions are never RESTARTING candidates; only a real `/clear` on a desktop or CLI session is ([docs/fleet.md](docs/fleet.md) "RESTARTING as built").
