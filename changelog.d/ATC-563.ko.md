### Changed
- MCC SERVER AUTO에서 `auto` 등급 PR을 착륙시키는 쪽은 하나다: 스위치가 on이고 서버의 `mcc-auto` job이 살아 있으면(마지막 3분 안에 점검을 시작함) MCC 세션의 `mcc land`가 서버가 착륙시킬 `auto` 등급 PR을 거절한다(`LAND 안 함 — MCC SERVER AUTO on …`). 서버가 거절·실패한 head는 전처럼 세션이 넘겨받고, `flagged`·`user` 등급, ESCALATE한 PR, 모드 `rts`는 바뀌지 않는다. MCC 매뉴얼은 스위치가 on인 동안 세션이 `auto` 등급 PR을 착륙시키지 않는다고 적는다.

### Fixed
- 경합에 진 머지(HTTP 405 "already in progress", 또는 다시 읽으니 같은 head로 이미 머지된 PR)는 실패한 착륙이 아니라 `already-landed`로 `mcc.jsonl`과 `mcc-auto` FLIGHT RECORDER 줄에 남는다. 거절·실패에도 오작동에도 세지 않고 설정 창에 따로 보인다. MCC 세션 자신의 `mcc land`는 `already landed`를 찍는다. 다른 405는 그대로 `failed`다. [docs/mcc.md](docs/mcc.md) "One lander for auto-tier PRs as built (ATC-563)".
