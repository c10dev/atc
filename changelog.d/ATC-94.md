### Added
- SQUELCH S1 (ATC-94, [docs/squelch.md](docs/squelch.md) "S1 as built"). `POST /api/squelch/:role` (`tower`, `mcc`, `occ`, `crosscheck`, `review`) fingerprints what that control session's `/tick` acts on, using the same briefs `atcctl` reads, and answers `{open, reason, quietSince, quietCount}`. The default mode is `shadow`: it is always open and records `shadow:quiet` or `shadow:<reason>` in `squelch.jsonl`, so nothing is dropped, and no hook calls it yet. `squelch.json` (atomic) holds the mode, the per-role heartbeat (50 min) and each role's last pass; `GET /api/squelch` returns it. An error is `200 fail-open`. Tests also pin that the four lines of a hook-blocked tick don't change AIRCRAFT health or FUEL readings.
