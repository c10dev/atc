### Added
- Auto-revert lane, live first with a flake guard (ATC-394, rework of ATC-351 PR 404 onto current `main`; [docs/autonomy.md](docs/autonomy.md) "C4 as built", [docs/mcc.md](docs/mcc.md), [docs/occ.md](docs/occ.md) 9.7).
  - When a merge MCC or AUTOLAND made turns `main` red, atc opens a revert PR of that merge and the next green head clears the stop. The lane is **on from the start** (no shadow mode); the SUPERVISOR's `off` switch (settings window, LANDING, "AUTO REVERT") stays.
  - Before reverting, atc re-runs the failing GitHub Actions run once on the same head. Green on re-run is a flake: nothing is reverted and it does not count toward the breaker. It reverts only if the check is red again and the merged PR's own head was green; a check that cannot be re-run, a re-run that does not finish and a PR whose own head was not green are `hold` lines instead.
  - Each revert and each flake caught is recorded and counted per day under the AUTO REVERT row; a reverted PR merged back unchanged within 24 hours (a revert of the revert, or the same files) counts as a misfire.
  - The breaker stays: a second new red head within an hour stops the lane and lowers AUTOLAND `merge` to `update` and MCC landing off. Human merges, migration (K1) and `user`-tier (K3) PRs are never reverted automatically.
