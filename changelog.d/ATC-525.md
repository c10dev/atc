### Added
- JOB TIMING: the server now counts, per source and per 5-minute window, how many times each periodic piece of work ran and how long it held the event loop (the 2-second snapshot tick and its stages, every job in `server/jobs/`, the `*-run` timers, the transcript `fs.watch` and FUEL scan, `claude agents --json` runs, and API routes), and appends one line per window to `job-timing/<date>.jsonl` (read-only `GET /api/job-timing`). It measures only and changes nothing on any screen. A SUPERVISOR-only switch `JOB TIMING` (default on) turns it off; `dropped` counts timings that were not kept ([docs/job-timing.md](docs/job-timing.md)).
