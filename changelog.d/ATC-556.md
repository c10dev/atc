### Added
- MCC SERVER AUTO: the server now lands `auto`-tier PRs that have an INSPECTION `pass` and meet every landing condition (L2–L8), and returns main to service when every PR in the range was landed by it, without an MCC turn. It is on by default behind a SUPERVISOR-only switch (`mcc.json` `serverAuto`, settings window MCC block); there is no `shadow` value. `flagged` and `user` tier, ESCALATEd PRs and mode `rts` are never landed by it. Each action leaves a `kind: "mcc-auto"` line in the FLIGHT RECORDER with its PR head or `from → to`; a land is re-read about 3 minutes later and counted as a misfire when it would now be refused (CI, INSPECTION, ESCALATE, HOLD). `mcc queue` carries the switch, the 7-day counts and the latest lines, so the MCC session sees a refused or failed land. See [docs/mcc.md](docs/mcc.md) "Server auto as built (ATC-556)".
