### Changed
- METRICS now holds the results in one place, as five sub-views: OPERATIONS, LEAKS, MISFIRE, FUEL and NETWORK (ATC-380, docs/layout.md Y5). NETWORK is no longer a tab: `#network` and old links open `#metrics/network`.
- **MISFIRE** is its own sub-view and covers every automatic lane (DISPATCH, SCHEDULE, FLEET PLAN) for the last 7 days: one row per lane with the switch, what the server did, the misfires and their share, then the DISPATCH daily lines and the latest SCHEDULE and FLEET PLAN misfires. It no longer sits under OPERATIONS. Read-only, no server change.
