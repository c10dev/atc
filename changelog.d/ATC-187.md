### Added
- LOGIN from the settings window: a registered folder that reads NOT LOGGED IN gets a LOGIN button. atc runs `claude auth login` for that folder and shows the login link; you log in in the browser and paste the code. After a successful login atc marks the folder's first-run screen as done and trusts the open AIRPORT folders in its `.claude.json` (only those fields, with a backup). The code is passed only to that process and never stored, and the process output never reaches the page (ATC-187, [docs/accounts.md](docs/accounts.md)).
