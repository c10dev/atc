### Changed
- `duty linear create` and `update` (with a body) check the work-order body (ATC-469). A missing or empty `## Goal`, `## Done when` or `## K effects`, or a `K3` line the server cannot read (`K3: none` included), is refused with HTTP 400 and nothing is written to Linear; the error names every broken part and the correct K3 line shape. A missing or unreadable `## Measure` creates the issue and returns a `warning`.
