### Changed
- The verification rule now tells sessions to run `npm test`, `npx tsc --noEmit -p .` and `npx vite build` through `node server/verify-gate-cli.ts -- <command>` (queued on the host, on the LAN desktop when it is up), and to use the plain command only when the gate is reported unavailable. All three checks must still pass. A transport failure of a remote run (exit 75 or 76, a local fallback) is not a test failure; a session reports the exit code and output it got, and never uses `ssh` or `scp` itself. Guards are unchanged. Applies to root `CLAUDE.md`, `atc-task` section 5 and [docs/verify-gate.md](docs/verify-gate.md) (ATC-519).
