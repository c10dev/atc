### Added
- VERIFY GATE remote execution: when the LAN desktop is reachable, `npm test`, `npx tsc --noEmit -p .` and `npx vite build` run there through the gate, with the command's own exit code and output; otherwise they run locally as before. Only those three commands go (word for word), to one fixed desktop whose address lives in the gate folder's `remote.json`, not in the repository. Source is sent minus an explicit exclusion list (`.env*`, `.git`, `~/.claude*`, keys, atc state). A connection lost before the command started falls back to local; one lost after it started exits 76 and is not re-run. Switch `verifyRemote` (settings window, default on, SUPERVISOR only); run records gain `where`, `syncMs` and `localReason`, and the VERIFY GATE block counts desktop runs, transport failures, remote command failures, local runs by reason and runs lost midway ([docs/verify-gate.md](docs/verify-gate.md)).
