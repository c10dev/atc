### Added
- IDEAS drawer and ADOPT (DUTY G4, ATC-232, [docs/duty.md](docs/duty.md) "G4 as built"): read the atc repository's open `idea` issues inside atc, and ask DUTY for a design outline with one click. Tier `user` (`duty/guard.mjs` changed).
  - `#ideas` and `#ideas/<n>` open a drawer (same shell as the FLIGHT and PR drawers) from an `IDEAS` link in the DUTY drawer head: a list sorted by last update, and a detail with the body, up to 20 comments and a `↗ GitHub` link. `GET /api/ideas` and `GET /api/ideas/:n` are read only, cached 60 s on open, with no polling. They read only `chaehy5665/atc` (a fixed repository; private ideas are never fetched) and answer `GitHub off` when `ATC_GITHUB=off`.
  - **ADOPT…** (one confirm, only while DUTY is on) sends a fixed message built on the server to DUTY through the existing `POST /api/duty/message`. DUTY reads the issue and answers in the chat with an outline (problem, facts to check, principles, steps). It writes no file and nothing on GitHub.
  - `atcctl duty idea <n>` (read only, body and comments between `BEGIN DATA`/`END DATA`) is allowed in `duty/guard.mjs`; `gh issue …` stays refused. Manual: `duty/CLAUDE.md` · `CLAUDE.en.md` "ADOPT". Guide page "DUTY 채팅" updated.
