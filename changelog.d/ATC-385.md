### Changed
- Alerts now end when their cause ends, so a CAUTION means something the SUPERVISOR can act on now (ATC-385):
  - A FLIGHT whose ticket is Done or Canceled is no longer followed, and all its FLIGHT FOLLOWING issues go with it. STRANDED stays, because the change is really missing from `main`.
  - An UNABLE ends when the PR it named is merged or closed, when its FLIGHT is closed, or when a later READBACK answers the same subject.
  - A BLOCKED in an arrival report ends when its FLIGHT is closed or a later report on that FLIGHT has no BLOCKED.
  - Changes left in a STAND with no session, and STANDs held by ended sessions, leave the CAUTION count after 6 hours and show as one `정리 대기 n건` cleanup line. Leftover changes are never deleted automatically.
  - An alert that an end rule removed and that comes back within 24 hours is counted. `GET /api/supervisor-alerts/ends` (read-only) shows the counts per rule and the CAUTION count with and without the end rules on the same state.
- The leak counter no longer closes and reopens a leak because its input went missing for a moment, for example right after an RTS restart before the first snapshot has PRs (it also waits for Linear). One continuous wait counts as one leak with its full minutes held, including older records in `leaks.jsonl`.
