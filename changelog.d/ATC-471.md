### Added
- A work order the SUPERVISOR asks for in the DUTY chat leaves without a second click: when the SUPERVISOR says to create it and go ahead, DUTY runs `duty linear create … --release`, the issue is created in Todo and that chat message is recorded as the release (`channel: duty-chat`, `via: create`, with the message as `words`). The server accepts it only in a turn a SUPERVISOR message started (a REVIEW turn or no turn is a 403), refuses a body with K effects (409, fire it on the RELEASE screen) and `--state Backlog` (400). Switch `chatRelease` (settings window, on by default, SUPERVISOR only) turns it off; the count of releases from this path and of those discarded, moved back to Backlog or revoked before the first LAUNCH shows next to the switch ([docs/dispatch.md](docs/dispatch.md)).
