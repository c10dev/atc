### Added
- `test-server` skill (ATC-357, [docs/skills.md](docs/skills.md)): one named skill runs an end-to-end check on a throwaway test server. `.claude/skills/test-server/testserver.mjs` (`start`, `stop <dir>`, `run -- <command>`) picks a free port in 7702-7799 with an atomic lock (two FLIGHTs can run at once), uses a fresh temporary state folder and `ATC_GITHUB=off`, kills only by saved PID (checked against `/proc/<pid>/environ`), and always removes the folder and port lock.
  - A request for production 7700, a port outside 7702-7799, or the production state folder is refused (exit 2). `atc-task` section 5 now sends the end-to-end check to the skill by name. The test glob in `npm test` also picks up `.claude/skills/**/*.test.mjs`. Tier `user`.
