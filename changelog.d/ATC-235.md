### Added
- DUTY L1 powers (DUTY D7a, ATC-235, [docs/duty.md](docs/duty.md) "D7a as built"): DUTY now does ENGINEERING's everyday work itself. It edits only its own `duty-*` STANDs, commits and pushes `claude/duty-*` branches, opens PRs, and writes Linear through the server. Off by default (`duty.json` `l1`). Tier `user` (DUTY's settings and guard, the root `CLAUDE.md`, `deploy/`).
  - `atcctl duty stand <name>` and `stand-done <name>`: the server creates or removes `.claude/worktrees/duty-<name>` on branch `claude/duty-<name>` from `origin/main` and hard-links `node_modules`. Names carry no ATC key.
  - The guard (fail-closed) lets `Edit` and `Write` reach only `.md` files inside a `duty-*` STAND, judged on the resolved path (a `..` segment is refused; symlinks are followed). Even inside a STAND it refuses the files that set its own powers: `duty/`, `*guard*`, `.claude/`, `.github/`, `package*.json`, `deploy/`, `hooks/`, the root `CLAUDE.md`, `.env*`, `.git*` and `node_modules`. git is limited to fixed forms in a STAND (`add`, `commit -m`, `push -u origin claude/duty-*`, `fetch origin`, `merge origin/main`; no `--amend`, `--no-verify` or `--force`), and `gh pr create` to `--base main --head claude/duty-*` with a title and never as a Draft. `gh pr merge|edit|api`, `curl`, `systemctl`, `kill`, `npm`, `claude` and `SendMessage` stay refused.
  - `atcctl duty linear create|update|comment`: the server writes the Linear ATC team with its own key (DUTY has no MCP). A new issue needs a priority; states stop at Backlog and Todo; only existing labels; no delete or close. One FLIGHT RECORDER line per call (`by: "DUTY"`), never the body. `POST /api/duty/stand|stand-done|linear` answer 403 when `l1` is off and to any request with an `Origin` header.
  - The root `CLAUDE.md` "ENGINEERING" moves to "DUTY" (the ENGINEERING session stays as break-glass under the same rules); `docs/naming.md` lists DUTY as a control session with L1; `duty/CLAUDE.md` gets the ENGINEERING duties and the root rules that apply. The ADOPT text now asks DUTY to write the design draft PR after the SUPERVISOR agrees in the chat. Guide page "DUTY 채팅" updated.
