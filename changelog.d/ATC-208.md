### Added
- FLIGHT drawer state button (ATC-208, DUTY G3): a **state move** row moves a Linear issue between its team's Backlog, Todo and Canceled states after one confirmation, and a `READY` chip marks a Backlog issue whose blockers are all Done or Canceled. It is the first place the atc server writes Linear: only a click on this screen does (`POST /api/flight/:key/state`; sessions, `atcctl` and `curl` cannot), only while the state is still what the drawer showed, never to Started or Done, one FLIGHT RECORDER line per move. See [docs/duty.md](docs/duty.md) and the [server README](server/README.md).
