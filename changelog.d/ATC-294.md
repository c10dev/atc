### Added
- CSS token lint (ATC-294): `npm test` fails on new literal colours, px/rem font sizes, `z-index` values that are not `var(--z-…)`, `transition: all` and `outline: none` without a `:focus-visible` rule in `web/src` (`.css` and `style={{…}}` / SVG colour attributes in `.tsx`). It is a ratchet over today's baseline (`web/css-lint-baseline.json`): only new violations fail, and a count that drops asks for the baseline to be lowered (`node server/css-lint.ts --update`).

### Changed
- A named z-index scale in `styles.css` (`--z-base` … `--z-drawer-panel`) replaces the bare values; the numbers are unchanged, so layering does not change. Font sizes that equalled a type-scale token (`12px`, `18px`) now use it.
