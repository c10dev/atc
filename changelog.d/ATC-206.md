### Added
- FLIGHT drawer and PR drawer (DUTY G1, ATC-206, [docs/duty.md](docs/duty.md) 3.6): click a FLIGHT number or a PR number, or open `#flight/<KEY>` or `#pr/<AIRPORT>/<n>`, to read a Linear issue or a GitHub PR inside atc, read only.
  - `GET /api/flight/:key/detail` and `GET /api/pr/:airport/:number/detail`: read on open, cached for 60 s, no background polling. The PR drawer adds landing state, tier and MCC INSPECTION for polled open PRs.
  - Markdown is rendered safely (raw HTML shown as text, images as links, `http(s)` links in a new tab with `rel="noreferrer"`). Tokens stay on the server. No write route.
