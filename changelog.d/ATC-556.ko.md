### Added
- MCC SERVER AUTO: 서버가 INSPECTION `pass`가 있고 착륙 조건(L2–L8)이 모두 맞는 `auto` 등급 PR을 MCC 세션의 턴 없이 착륙시키고, 범위의 PR이 모두 서버가 착륙시킨 것이면 main을 RETURN TO SERVICE한다. SUPERVISOR 전용 스위치(`mcc.json` `serverAuto`, 설정 창 MCC 블록) 뒤에서 기본 on으로 나가고 `shadow` 값은 없다. `flagged`·`user` 등급, ESCALATE한 PR, 모드 `rts`는 서버가 착륙시키지 않는다. 동작마다 FLIGHT RECORDER에 `kind: "mcc-auto"` 줄이 남고(PR head 또는 `from → to`), 착륙은 약 3분 뒤 다시 읽어 지금이라면 거절됐을 조건(CI·INSPECTION·ESCALATE·HOLD)이 있으면 오작동으로 센다. `mcc queue`에 스위치·최근 7일 숫자·최근 줄이 실려 MCC 세션이 거절·실패한 착륙을 본다.
