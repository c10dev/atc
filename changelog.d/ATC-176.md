### Added
- READABILITY R0 (ATC-176, [docs/readability.md](docs/readability.md)): atc now measures how well the radio works, and only measures. `readabilityOf` computes reply latency (median, p90), no-reply and overdue counts, UNABLE counts by reason class (`no-merge`, `wrong-target`, `stale`, `busy`, `blocked`, `other`, `none`), message size in characters and estimated tokens (characters ÷ 2.5, the received size includes the envelope), compliance where the records show it (GO AROUND → new PR head, FLIGHT PLAN READBACK → ARRIVED, RECALL → `recalled`; otherwise `unknown`) and phraseology violations from a reply's first line (missing head, multi-line UNABLE, wrong id), per frequency, kind and AIRCRAFT.
  - The server reads the first line (at most 200 characters) and the length of each team reply from the TOWER and OCC transcripts, read only; no message text is kept. It appends one line per UTC day to the new state file `readability.jsonl`, backfills every day from 2026-09-26 on the first run and never writes a day twice. Each line lists that day's merges that touched the phraseology (from `git log` on origin/main: manuals, skills, `server/response.ts`, the message text builders) and is also cut at their times. `GET /api/readability?days=N` returns the stored lines plus today's partial metrics. No screen yet.
  - Nothing that is measured changed: no phraseology, manual, `atcctl` or guard edits. RADIO transmissions gained an optional `closedBy` (`cancel`, `expire`, `supersede`, `delivered`, `recall`) for a call closed without a reply.
