### Added
- GO AROUND (ATC-128, [docs/guide/radio.md](docs/guide/radio.md), [docs/occ.md](docs/occ.md)): atc detects a PR that conflicts with base, falls behind it, or whose LAND-text predecessor just merged, and builds an action message for the holders of its STAND.
  - New CLEARANCE type `GO AROUND` (W/U: READBACK, or UNABLE with a reason). `atcctl issue <session> "GO AROUND" -- <text>` (also `GO-AROUND`).
  - `landingQueue[].goAround` carries the text (which merges caused it, the files they share with the PR, the action) and an `action`: `send`, `sent` (already sent for this head), or `supervisor` (no holder, or a second GO AROUND on the PR within an hour). It is derived from state, so a server restart doesn't hide it.
  - Events `landing.conflict` (once per PR head, also when a PR enters the LANDING SEQUENCE already conflicting) and `landing.prevMerged`, with the merged PRs and shared files.
  - atc never resolves a conflict itself.

- PR 194 waited seven minutes for its conflict notice on 2026-09-29: it entered the LANDING SEQUENCE already `dirty` in a TOWER pass with `reset: true`, which sends no APPROACH INFO, and no later event fired. The state-based `goAround` covers it.
