### Added
- Per-AIRPORT "teams don't merge here" (ATC-154, [docs/mac-app.md](docs/mac-app.md)): an optional `teamsMerge` in `airports.json` (only `false` is written; old files read as `true`). For a PR on an AIRPORT with `teamsMerge: false`, the TOWER brief's `landBy` is `supervisor` whatever the tier, so no `LAND` goes out that would end in `UNABLE`. The MCC AIRPORT keeps its ATC-151 rules and other AIRPORTs are unchanged. The SUPERVISOR sets it on the AIRPORTS screen ("팀 머지" ON/OFF, screen requests only; sessions get `403` and never write `airports.json`).
