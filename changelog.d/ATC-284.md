### Changed
- Design language L5a, icon set (ATC-284, [docs/design-language.md](docs/design-language.md) 3.5.6). The web screen uses one outline icon set, Lucide (`lucide-react` 1.49.0, imported per icon), through a small `Icon` / `IconButton` wrapper (14 or 16 px, stroke 1.5, theme colour, `aria-hidden`; an icon-only button must have a label). Text glyphs that acted as icons are replaced: fold chevrons (`▸ ▾`), close (`× ✕`), external link (`↗`), back (`←`), play (`▶`), and the FLEET card's `⋯` menu and copy icon. Glyphs that are text or data (`→` in sentences and routes, `✓ ✗ ○` in criteria and status lists, `✈`, `×n`) stay.
