### Changed
- ARRIVED report: `TESTS n/a` is accepted for a PR with no code or test changes (docs, config, CI), so OCC no longer drops the fixed fields (ATC-209, [docs/dispatch.md](docs/dispatch.md) "Arrival reports as built").
  - `dispatch report --tests n/a` stores `tests: { na: true }` (the `ArrivalReport` shape stays backward compatible) and the report line shows `TESTS n/a`; it is never read as 0/0 or a failure. Other free text is still rejected, and OCC never guesses a number.
  - The `atc-task` skill (section 8), root `CLAUDE.md` 교신 and the OCC manual say when to use it. The `TESTS` line stays mandatory.
