### Added
- DUTY REVIEW: the server starts a DUTY turn by itself, on a schedule (4 h) or when a trigger fires (an AIRCRAFT idle for 20 min while Todo FLIGHTs wait, or a leak open for 60 min). DUTY reads the landing queue, the DISPATCH plan, leaks and alerts, leaves a short Korean summary in the chat and proposes fixes as ATC issues in Backlog, each with its evidence. It never sets Todo (the server refuses it in a review turn) and does not repeat what an open issue covers. One switch, Settings → OPERATIONS → DUTY REVIEW, on by default, only the SUPERVISOR changes it. Reviews, proposals, fired and discarded proposals are counted per day (`GET /api/duty/review`, shown in the settings window) (ATC-396).
- `duty linear create --blocked-by ATC-n` (repeatable): the new issue waits behind a FLIGHT already accepted.
