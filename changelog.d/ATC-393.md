### Changed
- Switch and job registry (ATC-393, [docs/switches.md](docs/switches.md)): a SUPERVISOR switch is one file in `server/switches/` (name, values, default, ⚠ modes, warnings, window row, save and record line) and a periodic server job is one file in `server/jobs/`. The settings PUT and GET, the mode line, the ⚠ confirmation, the settings search, the settings window and `server/index.ts` read the declarations, so two PRs that each add a switch or a job no longer conflict. Every existing switch behaves as before.

### Added
- CODEX LANE switch (ATC-393): settings window LANDING turns the silent review lane of ATC-386 off (`codex-lane.json` `auto`, default on, SUPERVISOR only; ⚠ when on).

### Fixed
- The silent review lane runs only for repositories that use Codex (not the MCC AIRPORT's) and the single-lane count keys a landing by AIRPORT as well as PR number and head (PR 429 review).
