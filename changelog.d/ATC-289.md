### Added
- Skill-call reader (ATC-289, [docs/readability.md](docs/readability.md)): atc counts `Skill` and sub-agent (`Agent`/`Task`) calls per session from the Claude transcripts of the control sessions and AIRCRAFT, keeping only session, session name, call name (with the plugin namespace) and time, never message text. It matches them to the `qrh.named` FLIGHT RECORDER lines: opened (the named checklist), opened-other (another `qrh-*`), not-opened, with the named → opened rate. Until `qrh.named` lines exist the counts are zero.
  - One line per UTC day is appended to the new state file `skill-usage.jsonl` (from 2026-10-01). `GET /api/skills/usage?days=N` returns the stored lines plus today's partial counts. Read-only on transcripts and state; no screen, and no text any session receives changed.
