### Added
- RELEASE tab (`#release`): the SUPERVISOR fires arrows from one screen. It lists the candidates (READY Backlog issues and agent proposals such as SCHEDULE NEW drafts), the Todo issues that are not released yet, and recent releases with the 7-day count by channel. Each row shows its priority and the K effects it declares before the click. Firing a READY issue moves it to Todo and records a screen release in one click (`POST /api/releases/fire`); an issue without a priority is not fired and links to its FLIGHT drawer. The release rules and checks are unchanged (ATC-376).

### Changed
- DISPATCH no longer has its own RELEASE block; it links to the RELEASE tab (ATC-376).
