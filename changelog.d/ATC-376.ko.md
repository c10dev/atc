### Added
- RELEASE 탭(`#release`): SUPERVISOR가 한 화면에서 화살을 쏜다. 후보(READY Backlog 이슈와 SCHEDULE NEW 초안 같은 에이전트 제안), 아직 발권하지 않은 Todo 이슈, 최근 발권과 지난 7일 채널별 수를 보인다. 줄마다 우선순위와 이슈가 선언한 K 효과가 클릭 전에 보인다. READY 이슈는 한 번의 클릭으로 Todo로 옮기고 화면 발권을 기록한다(`POST /api/releases/fire`). 우선순위가 없는 이슈는 쏘지 않고 FLIGHT 서랍으로 안내한다. 발권 규칙과 검사는 그대로다 (ATC-376).

### Changed
- DISPATCH 탭에서 자체 RELEASE 블록을 없애고 RELEASE 탭으로 가는 링크를 둔다 (ATC-376).
