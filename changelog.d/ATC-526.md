### Added
- Other AIRPORT repos on this host can use the two host-load gates. A Playwright script that sets its browser executable to the gated launcher (`node server/browser-gate-cli.ts --print-launcher` prints the path) takes a slot from the same pool as MCP-launched Chrome. `node server/verify-gate-cli.ts -- <command>` run from another repo's folder queues the command locally through the same slots and `node` shim, and goes to the desktop only if the command is on that repo's allow-list in `repos.json` in the gate folder (an empty or missing list means none do; the dependency cache on the desktop is per repo). Runs now record the repo's folder name, and the VERIFY GATE and BROWSER GATE blocks of the settings window show per-repo counts for all time and the last 7 days. Same switches, still fail-open ([docs/verify-gate.md](docs/verify-gate.md), [docs/browser-gate.md](docs/browser-gate.md)).
