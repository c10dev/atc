### Added
- DUTY REVIEW has a fourth trigger, `empty`: when an AIRCRAFT can take work and no Todo FLIGHT is waiting for 20 continuous minutes, the server starts a DUTY turn that lines up the next work, in this order: the READY Backlog worth firing now (named in the Korean summary), design-document steps with no issue yet, then small `idea` issues a single FLIGHT can finish. Steps 2 and 3 file at most 3 Backlog issues together; DUTY still cannot set Todo ([docs/duty.md](docs/duty.md) REVIEW).
- Settings → OPERATIONS → **DUTY REVIEW EMPTY** switches only this trigger off (`duty.json` `reviewEmpty`, default on; `reviewEmptyMin` 20, `reviewEmptyGapMin` 60). Under it the settings window counts wasted `empty` turns and turns whose issues were discarded; `GET /api/duty/review` returns the same counts as `empty`.
