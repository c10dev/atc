### Changed
- Chips, tags and dots share one base each, in `web/src/kit/chips.css` (ATC-412, [docs/design-language.md](docs/design-language.md) 4.4). The alert code chips, the drawer chips and TIER tag, the FLEET and CHECKRIDE rating chips and the `STAND n` tag now sit on `.chip` or `.tag` and keep only what differs. The drawer chips are pills now (they had a 3 px corner). Every `.tag` is now mono, bold and uppercase with the wider letter spacing of design-language 4.4, so tags on other screens (for example `BG auto` becomes `BG AUTO`) change too. Chips have no fill, as before.
- The activity line no longer tells its phase by colour alone: a running tool is a filled dot, waiting on the model a ring, idle a short bar, and a screen-reader word names the phase. Session status dots (AIRBORNE, idle, NORDO) get the same treatment: filled, bar, ring.
