### Added
- MERGE in the PR drawer (DUTY G2, ATC-207, [docs/duty.md](docs/duty.md) "G2 as built"): for a `user`-tier PR of the MCC AIRPORT (or one MCC ESCALATEd) that is CLEARED TO LAND, a `MERGE…` button asks once more and then merges through atc, pinned to the exact head with the AIRPORT's merge method and never with auto-merge. `POST /api/pr/:airport/:number/merge` takes only a request from this screen (no atcctl command, so no session can call it), re-reads the PR and its changed files from GitHub, refuses `auto` and `flagged` PRs (those are MCC's), a moved head (409 with the new head), a PR that is not CLEARED or is on HOLD, and writes one FLIGHT RECORDER line per attempt. `server/pr-merge-run.ts` joins the side-effect list in `deploy/landing-tier.mjs`. See [Deploying](docs/guide/deploy.md).
