### Changed

- Settings window (ATC-189): the logo now opens a wide centered window with a side menu instead of the 400px popover with top tabs. ACCOUNTS has its own section (it was a block in AGENTS), with folder cards, a REGISTRY heading and themed buttons. The AUTOMATION tab is split into LANDING (AUTOLAND, MCC, REVIEW) and OPERATIONS (FUEL, REPOSITION, CONTROL RECYCLE, JUDGES), both with the current-policy line on top. A search box at the top of the menu finds a block by code, Korean name, row name or env key, then jumps and scrolls to it. Esc clears the search first and then closes the window. On a phone the window fills the screen and the menu becomes a horizontal row. Saved values and the settings API are unchanged.
