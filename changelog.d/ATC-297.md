### Added
- Quiet ticks (ATC-297, [docs/squelch.md](docs/squelch.md)): SQUELCH now records **why** a tick opened, runs a tighter fingerprint beside the live one, and TOWER's `/tick` is one call when nothing is to be done.
  - Opens-by-field: a `signal` decision in `squelch.jsonl` carries `fields`, the paths of the projected fields that changed (no values). `GET /api/squelch/opens?days=N` joins the decisions with the control session transcripts (tool-call times only) and returns, per role, which fields open ticks that then did nothing (two tool calls or fewer) and which opened ticks that worked. Finding: TOWER's alert text carries a running duration (`5분째`), so it changed every minute while a session waited on approval.
  - Fingerprint `v2` runs in shadow for every role (`would: open|quiet`, `fp2`, `fields2` on each decision); only TOWER differs from `v1` (ATC-log-only events, info health entries and alert durations no longer count). `config.fingerprint.<role>` (`v1` default) in `squelch.json` picks the deciding one; this change flips nothing. A `v2` failure falls back to `v1`, a `v1` failure opens (fail-open unchanged, `controller/squelch.mjs` untouched). `v2.wrongSkips` is the count of ticks `v2` would have skipped that worked.
  - `node atcctl.mjs tick <role>` runs `manual check`, the brief and (when nothing is to be done) the `ack` in one call: `TICK QUIET tower — nothing to act on`, or `TICK ACT tower` with the reasons and the brief, or `CHANGED …` first when the manual changed (no ack). The server decides with the pure `actionable(role, inputs)` (`GET /api/tick/<role>`), which treats anything it does not know as work. Only TOWER's `/tick` uses it; the other roles and every guard are unchanged.
