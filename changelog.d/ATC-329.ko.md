### 추가
- AUTOLAND 마이그레이션 게이트(ATC-329): 상태 폴더 `airports.json`에 선택 설정 `hostedDb`(`{ provider: "supabase", projectRef, migrationsDir }`)를 둔 AIRPORT에서는, 마이그레이션을 더하는 PR이 새 마이그레이션 버전이 모두 호스티드 DB에 이미 적혀 있을 때만 위임된다(`reviewedSecurity: delegate`). atc는 적용된 버전을 읽기만 하고(Supabase Management API `GET`, 토큰은 `.env.local`) 마이그레이션을 적용하거나 SQL을 돌리지 않는다. 기존 마이그레이션 수정, 없는 버전, 읽기 실패는 계속 SUPERVISOR 몫이고, AUTOLAND는 머지 직전에 캐시 없이 다시 읽는다. `hostedDb`가 없으면 달라지는 것이 없고, 시험 서버는 `ATC_HOSTED_DB=on`이 있어야만 읽는다([docs/occ.ko.md](docs/occ.ko.md) 9.7).
