### Added
- CONTROL SESSIONS bulk actions (ATC-255, [docs/fleet.md](docs/fleet.md) 8.5.4): **LAUNCH ALL**, **RESTART ALL**, **STOP ALL** and **ALIGN** under the FLEET CONTROL group header. Each opens a preview first, then runs after one confirmed click.
  - The preview lists the order (TOWER, OCC, MCC, CROSSCHECK, REVIEW; STOP goes the other way), the action and reason per session, and ACCOUNT drift (for example TOWER on `acct-3`, intended `acct-1`). **ALIGN** restarts only the drifted sessions on the intended ACCOUNT. Sessions that would lose work (mid-turn, RTS, OCC unsent FLIGHT PLANs …) are held unless the SUPERVISOR ticks "proceed anyway".
  - One session at a time through the same functions as the FLEET buttons and CONTROL RECYCLE. `GET` / `POST /api/control/bulk` (POST: SUPERVISOR only, runs only what the screen previewed). FLIGHT RECORDER: the per-session lines plus one `control` `bulk` line per run. No guard changed.
  - A recovery banner (header CONTROL strip and the CONTROL group) appears when no control session that can be launched is live, for example after a host reboot.
