### Added
- ACCOUNTS readers (ATC-146, [docs/accounts.md](docs/accounts.md) 5.1): `fleet.json` gets an optional top-level `accounts` registry (`{ "<label>": { "configDir": "<absolute path under $HOME, named .claude…>" } }`, no email or token). atc reads sessions, jobs, transcripts and FUEL from every registered folder (`~/.claude` is always read, label `default` unless mapped), and `Session.account` is the folder a session was found in. Set in the settings window (AGENTS tab, ACCOUNTS block, SUPERVISOR only); each folder shows `loggedIn`, `authMethod` and warnings for a missing statusline or `claim.mjs`/`health.mjs` hook.
- FUEL groups statusline records by the observed ACCOUNT; a FLEET row whose session runs in another folder shows `acct-1 (home acct-2)`. With no registry entry nothing changes.
