### Added
- `GET /api/supervisor-summary` and a `summary` SSE topic (ATC-153): one server-side summary of the SUPERVISOR alert list for menu bar clients and atc-app — `{ v: 1, at, master, counts, pending, fuel, rts, working, needsYou }`, sent again only when its content changes. Read only; no new write route, auth or CORS. The field list is in the [server README](server/README.md).
- `GET /api/events?topics=snapshot,alert,version,summary`: opt in to the events you need (unknown topic: `400`; `ping` always). Without `topics` the stream is what it was, everything except `summary`.

### Changed
- The SwiftBar plugin takes its title numbers, FUEL, DISPATCH approvals, RTS and working counts from `/api/supervisor-summary` instead of counting itself, so it needs this server version. Its RTS line now shows `from → to` instead of the free-text detail.
