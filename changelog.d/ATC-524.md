### Changed
- VERIFY GATE remembers for a short time (default 60 s, `remoteAbsentSec` / `ATC_GATE_REMOTE_ABSENT_SEC`, `0` = off) that the LAN desktop was found absent, so the following gated runs skip the reachability probe and run locally at once; the first run after the window probes again, and a probe that finds the desktop clears the memory. Skipped runs still count as `desktop-absent` ([docs/verify-gate.md](docs/verify-gate.md)).
