- CONTEXT SIZE per AIRCRAFT (ATC-69, [docs/fleet.md](docs/fleet.md) 8.6 "REFRESH as built"). The reasons carry the size and the saving priced with the F5 table: the cache write the next cold wake would not need, and the read per turn.
