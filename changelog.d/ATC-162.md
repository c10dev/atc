### Added
- Voice callouts (ATC-162, [docs/guide/voice.md](docs/guide/voice.md), [docs/guide/alerts.md](docs/guide/alerts.md)): audio is unlocked by the first click or key press anywhere in the page while sound is on and locked, and atc first tries `resume()` before giving up (also when the tab becomes visible or the window gets focus), which covers a context the browser suspended after the page already had a gesture and Safari's `interrupted` state.
- A persistent header chip `🔇 소리 잠김 — 클릭하면 켜짐` while sound is on and audio is locked; clicking it unlocks. Colours come from `:root` tokens.
- A WARNING or CALL that arrives while audio is locked is kept as "missed" and shown in the tab title (`🔇1`). On unlock only the highest missed item that is still present is played, once (with its voice if voice is on); quiet hours still apply.
- DISPATCH voice phrases say what is asked: "Supervisor, dispatch requests ATC one four six for HOTEL, request decision." for ASSIGN and "Supervisor, dispatch requests release of ATC one four six, request decision." for RELEASE. The `pending|proposal` alert item gains an optional `ask` field (`assign`/`release`); the alert key is unchanged.
- SCHEDULE decisions as CALL in approval mode: each `draft`, `agreed` or `disagreed` SCHEDULE op becomes a `pending|schedule|<id>` item (level advisory, link `#schedule`, `ask` = the op kind in lower case) with the phrase "Supervisor, schedule requests tail on ATC one four six, request decision." In shadow mode there is no item. `GET /api/supervisor-summary` counts them in `pending.schedule`.
