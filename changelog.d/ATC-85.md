### Changed
- The CONTEXT/FOB window now comes from the session when it says so, instead of the 200k guess (ATC-85, [docs/fleet.md](docs/fleet.md) 8.6 "CONTEXT window from the session as built"). CLI sessions: the FUEL statusline hook also records `context_window_size` and the model id in `fuel/<sessionId>.jsonl` (a line is appended only when a value changes, and a line without `rate_limits` is kept; old lines are still read). Desktop sessions: the last `/model` output in the transcript (`Set model to `claude-sonnet-5-5[1m]``). Then the ATC-69 rule. `windowSource` gains `statusline` and `model-command`, and the FLEET CONTEXT/FOB tooltip names the source. A switch to a 200k model with a 324k conversation now reads a 200k window (FOB 0 %) instead of 1M. Requests before a session's last `/model` no longer count towards the `observed` guess. The hook and the record format are `user` tier. No threshold, FOB label or REFRESH rule changed.
