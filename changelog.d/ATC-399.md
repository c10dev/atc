### Changed
- Released K3 effects now reach the classifier as Linear stores them. A declaration line such as `K3\[Security Weaken\]: … | files: server/a\_b.ts` is read with its Markdown escapes undone; before, every declaration written through Linear counted as unparsed and built no allow entry (ATC-399).
- Two more soft_deny labels can be declared: `Security Test Removal` (the entry names which tests are removed or skipped) and `Instruction Poisoning` (the entry says the instruction file edit is a wanted change the SUPERVISOR authorized, so a flag on it is a false positive, for the declared files only). Every other label stays undeclarable; `docs/autonomy.md` (C9) now lists all 72 labels from `claude auto-mode defaults` as declarable or not, with a reason each.
