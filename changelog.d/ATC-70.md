### Changed
- DIRECT briefs show a PR mention as its link text (ATC-70, [docs/dispatch.md](docs/dispatch.md) "DIRECT briefs"). Linear stores a mentioned GitHub PR as a link to its own review page, and the brief carried it whole: `[chaehy5665/atc#134](https://linear.app/vocado/review/fuel-f8-screens-…)`, about 110 of the goal's 600 characters each, with a URL a team can't use. `briefTextOf` now turns a markdown link to `linear.app/<workspace>/review/<slug>` into its text (`chaehy5665/atc#134`); text that isn't `owner/repo#N` is kept as written. A link without text, a bare review URL, code spans and fenced blocks are unchanged, and so are other links, the brief lines, the section rules and the limits. The 600-character goal is counted on the cleaned text.
