- 시험이 더는 운영 상태 폴더에 쓰지 못한다. FLIGHT RECORDER(`server/recorder.ts`)와 다른 모듈 넷(`clearances.ts`, `dispatch.ts`, `landing-review.ts`, `proposals.ts`)은 import 때 `config.stateDir`로 파일 경로를 고정해서, import 뒤에 `config.stateDir`를 임시 폴더로 바꾼 시험도 `~/.local/state/atc/`에 썼다. 2026-10-06에 `server/update-run.test.ts`가 그렇게 가짜 `mcc-auto` RTS 줄 20개를 썼다. 이제 쓸 때마다 경로를 읽고, `config.airportsFile`은 따로 정하지 않으면 지금의 `stateDir`를 따른다.
- 막음(`server/state-guard.ts`): `node --test` 안에서 운영 상태 폴더를 가리킨 `config.stateDir`·`config.airportsFile`을 읽으면 던지고, 오류를 잡아도 그 시험 파일은 실패한다. 경로 문자열만 비교한다. 운영 폴더에 닿던 시험 파일 23개는 이제 `./test-hermetic.ts`를 첫 import로 둔다.
