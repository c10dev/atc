### Added
- VERIFY GATE: `node server/verify-gate-cli.ts -- <command>` runs a heavy verification command (`npm test`, `tsc`, `vite build`) behind a host-wide limit (2 at a time by default). A run with no free slot waits its turn and says so on stderr, past the wait limit it exits 75, and if the gate itself cannot work it runs the command directly and counts the fallback. A gated `node --test` also gets a test-process limit. Exit code and output are the command's own. Switch `verifyGate` (settings window, default on, SUPERVISOR only); the settings window shows the counters, and every run is recorded in `runs.jsonl` ([docs/verify-gate.md](docs/verify-gate.md)).
