### 추가
- 설정 창에서 SHARE MEMORY(AGENTS → ACCOUNTS): ACCOUNT 폴더 줄에 `MEMORY shared ✓`·`MEMORY separate`·`MEMORY conflict`가 보이고, 버튼을 누르면 atc 체크아웃과 열린 AIRPORT의 Claude Code memory 폴더를 `~/.claude` 것으로 잇는다. `acct-1`·`acct-3` 세션도 같은 규칙과 교훈을 본다. 빈 memory 폴더는 링크로 바꾸고, 이미 파일이 든 폴더는 건드리지 않고 충돌로 두며 파일 이름만 보인다. ADD ACCOUNT도 새 폴더에 같은 일을 한다(ATC-191, [docs/accounts.md](docs/accounts.md)).
