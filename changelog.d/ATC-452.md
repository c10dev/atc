### Added
- An ATC FLIGHT can run in a Claude Code cloud session. The new SessionStart hook `hooks/cloud-setup.mjs` runs only when `CLAUDE_CODE_REMOTE=true`: it installs Node 24 if the VM has an older one and runs `npm ci`, so tests, `tsc` and `vite build` work from the first turn; locally it does nothing and exits 0. `atc-task` section 2 says what changes in the cloud (own clone and `claude/atc-<n>-…` branch, spec from the prompt, report in the session and a PR comment, no Playwright), and [docs/cloud.md](docs/cloud.md) gives the SUPERVISOR the one-time setup and how to send a FLIGHT (ATC-452).
