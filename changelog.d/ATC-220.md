### Added
- DUTY chat (DUTY D2, ATC-220, [docs/duty.md](docs/duty.md) "D2 as built"): the atc server now owns one `claude -p` stream-json process for DUTY, and the SUPERVISOR talks to it in a text drawer. Off by default (`duty.enabled` in `duty.json`, switch in Settings → OPERATIONS → DUTY, ⚠ to turn on). Nothing runs against prod until the SUPERVISOR turns it on.
  - Runtime (`server/duty-run.ts`, the side-effect file D1 pre-registered): spawned on the first message with `dutyArgvOf` and `cleanEnv(<ACCOUNT dir>)`; one process, one input queue (a second message waits and its sender sees "DUTY is answering"); **stop** writes an `interrupt` control message and the process stays up; after `duty.idleMin` (default 30) of no input it ends by closing stdin and the next message resumes with `--resume <id>` (`duty-session.json`); **NEW SHIFT** starts the next message with a fresh session id; a crash shows as `down` with the last stderr line, and three crashes in five minutes stay `down` until NEW SHIFT.
  - Pure parts with tests: `duty-stream.ts` (stream-json lines → `user`/`text`/`tool`/`state`/`usage` events; tool name and a one-line summary only, never inputs or outputs; unknown lines ignored, malformed lines counted) and `duty-machine.ts` (idle → thinking → idle, queue, idle timeout, crash backoff).
  - `POST /api/duty/message` (text, and one pasted PNG/JPEG/WebP up to 5 MB), `/api/duty/stop` and `/api/duty/new-shift` are SUPERVISOR-only (`fromThisApp` Origin check; `atcctl` has no way to send a DUTY message) and refuse with a reason when DUTY is off. `GET /api/duty/history?before=` pages `duty.jsonl`; `GET /api/duty/status` gives state, ACCOUNT, short session id, context and the CAP. `/api/events?topics=duty` streams the events (opt-in).
  - `duty.jsonl`, `duty-session.json` and `duty-images/` live in the state folder, never in the repository. The log holds user text, final DUTY text, tool name + summary lines and turn usage.
  - Screen: a `● DUTY` readout in the header (only when on; the dot is the state) opens the DUTY drawer, also at `#duty` over any tab. About 440 px on the right, full screen on a phone; Esc, backdrop, × and Back close it. Head line `DUTY · acct-2 · context 12/250k` and NEW SHIFT with a confirm step; streaming chat, small muted tool lines, Enter to send, Shift+Enter for a new line, paste an image, and a stop button while DUTY is answering. Cards and the queue row are D3; DUTY's text is never read aloud.
  - Guide page "DUTY 채팅" in the DOCS tab.
