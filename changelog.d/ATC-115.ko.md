### 문서
- 작업 규칙: 워크트리는 `/home/c10/projects/worktrees/…`뿐 아니라 main 체크아웃의 `.claude/worktrees/`(Claude Code 워크트리 도구, 브랜치 `worktree-<이름>`)에도 둘 수 있다. main 체크아웃은 손대지 않고(`git clean`·`git stash` 금지), 치우는 것은 `git worktree remove`나 `ExitWorktree`다(ATC-115, 루트 `CLAUDE.md`, [docs/naming.ko.md](docs/naming.ko.md)).
  - 백그라운드 AIRCRAFT는 STAND를 `EnterWorktree name=…`으로 만들고, 다음 FLIGHT는 `ExitWorktree action=keep` 뒤 새 `name`으로 옮긴다. `.claude/worktrees/` 밖으로 `EnterWorktree path=`를 하면 승인을 물어 백그라운드 세션이 멈춘다.
  - `worktree-` 브랜치도 `claude/` 브랜치와 똑같이 연결된다(key 파싱 테스트가 지킨다).
