### Added
- FRESH START at assignment (ATC-73, [docs/fleet.md](docs/fleet.md) 8.6, [docs/dispatch.md](docs/dispatch.md)). REFRESH is only offered while an AIRCRAFT rests, so an assignment that arrives first cancelled it (TEAM_F flew ATC-311 on a 794k context). An approved ASSIGN card whose AIRCRAFT runs a **background** session over the REFRESH threshold, with no STAND of an unfinished FLIGHT, now has **FRESH START…** (SUPERVISOR's screen only, never automatic): atc STOPs the session and LAUNCHes a new one whose first prompt is the CREW BRIEFING followed by the FLIGHT PLAN. The proposal counts as sent with `via: "fresh-start"` (READBACK, DEPARTED, LOGBOOK and FUEL attribution unchanged) and OCC never sends it again (`dispatch release` answers 409 for it). Desktop and terminal sessions are never stopped; when the button is not offered the card shows why. FLIGHT RECORDER gets `dispatch` `fresh-start` lines for the STOP, the LAUNCH and the send. The FLEET card's LAUNCH options take an optional FLIGHT: the first prompt is then the CREW BRIEFING and the DIRECT brief.
