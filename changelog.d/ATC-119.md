### Changed
- OCC sends FLIGHT PLAN, RECALL and CREW CHANGE by ID (ATC-119, [docs/occ.md](docs/occ.md) section 8.3).
  - OCC sends only the header (`[DISPATCH D-0094]`, `[DISPATCH D-0094] RECALL`, `[OCC CC-0003]`); send-guard runs every check as before, then its PreToolUse hook replaces the message with the text atc stored. Anything after the header, and every other case that was blocked, is still blocked; the full text still passes when it matches exactly.
  - `atcctl dispatch release`, `dispatch recall-send` and `crew-change send` print a `SEND:` line with the header to send, above the full text (kept for the log).
