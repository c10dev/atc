### Fixed
- STRANDED no longer stays for 14 days when a stacked merge was carried to the default branch by a squash-merged PR (ATC-216, [docs/occ.md](docs/occ.md) 9.4). Besides the default branch and the open PRs into it, atc now also checks the head of a PR merged into the default branch at or after the stranded PR; a squash merge of a head that contains the commit counts as reaching main. A merge that nothing carried is still STRANDED, a failed `compare` still raises nothing, and the alert text and level are unchanged. Read-only GitHub API only.
