### Changed
- CONTROL RECYCLE follow-up (ATC-175, [docs/control-recycle.md](docs/control-recycle.md) 2.5). Defaults are unchanged: mode `off`, `auto.OCC: false`.
  - "Between turns" is `tempo: idle` and not `blocked` (so `working/idle` counts too).
  - A session over its cap that waits longer than `waitAlertMin` (default 60, in `control-recycle.json`) raises one CAUTION alert `recycle|wait|<session>` naming the blocks; in `shadow` it also writes one `would-wait` line per session per cooldown.
  - After an unconfirmed STOP atc tries `launchControl` anyway (it refuses while a live row exists). The record keeps the LAUNCH result and the alert says whether the session is running.
  - TOWER waits only above 5 un-acked `brief` events (a fresh TOWER replays the rest).
  - Changing a cap or an `auto` value writes one `recycle-caps` / `recycle-auto` FLIGHT RECORDER line (from, to). Switching a session to `auto` (OCC too) needs the same ⚠ confirm as mode `on`.
  - OCC's safe moment is the ATC-169 `restartSafetyOf` result (the same as `dispatch brief` `restartSafety`) plus an open CREW CHANGE, replacing the duplicated counts.
