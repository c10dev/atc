### Added
- AUTOLAND migration gate (ATC-329): on an AIRPORT with an optional `hostedDb` setting in the state directory's `airports.json` (`{ provider: "supabase", projectRef, migrationsDir }`), a PR that adds migrations can be delegated (`reviewedSecurity: delegate`) only once every new migration version is already recorded on the hosted database. atc reads the applied versions read-only (Supabase Management API `GET`, token from `.env.local`) and never applies migrations or runs SQL; edited existing migrations, missing versions and failed reads stay with the SUPERVISOR, and AUTOLAND re-reads with no cache right before merging. With `hostedDb` unset nothing changes; test servers read nothing unless `ATC_HOSTED_DB=on` ([docs/occ.md](docs/occ.md) 9.7).
