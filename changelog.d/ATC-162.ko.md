### Added
- 음성 콜아웃(ATC-162, [docs/guide/voice.md](docs/guide/voice.md), [docs/guide/alerts.md](docs/guide/alerts.md)): 소리가 켜져 있는데 잠겨 있으면 페이지 어디서든 첫 클릭이나 키 입력이 오디오를 풀고, 포기하기 전에 먼저 `resume()`을 해 봅니다(탭이 다시 보일 때와 창이 초점을 받을 때도). 이미 제스처를 받은 뒤 브라우저가 멈춘 컨텍스트와 Safari의 `interrupted` 상태를 다룹니다.
- 소리가 켜져 있는데 잠겨 있는 동안 헤더에 `🔇 소리 잠김 — 클릭하면 켜짐` 칩이 계속 뜨고, 누르면 풉니다. 색은 `:root` 토큰만 씁니다.
- 잠겨 있는 동안 온 WARNING·CALL은 "놓침"으로 남고 탭 제목에 `🔇1`로 보입니다. 풀리면 아직 있는 것 중 가장 높은 하나만 한 번 울립니다(음성이 켜져 있으면 음성도). 조용한 시간은 그대로 적용됩니다.
- DISPATCH 음성 문구가 무엇을 청하는지 말합니다: ASSIGN은 "Supervisor, dispatch requests ATC one four six for HOTEL, request decision.", RELEASE는 "Supervisor, dispatch requests release of ATC one four six, request decision.". `pending|proposal` 알림 항목에 선택 필드 `ask`(`assign`·`release`)가 생기고 알림 key는 그대로입니다.
- approval 모드의 SCHEDULE 판정을 CALL로: `draft`·`agreed`·`disagreed` 상태의 SCHEDULE 작업마다 `pending|schedule|<id>` 항목(등급 advisory, 링크 `#schedule`, `ask`는 작업 종류 소문자)과 "Supervisor, schedule requests tail on ATC one four six, request decision." 문구가 생깁니다. shadow 모드에서는 항목이 없습니다. `GET /api/supervisor-summary`의 `pending.schedule`이 그 수를 셉니다.
