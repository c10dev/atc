### Changed
- HOME shows one to-do list. The SUPERVISOR QUEUE (`GET /api/supervisor/queue`) now also holds `ALERT` (WARNING and CAUTION alerts the SUPERVISOR can act on), `STUCK` (FLIGHTs past their stuck limit), `EFFECT` (deployed FLIGHTs whose EFFECT CHECK verdict is `not improved` or `worse` and not marked wrong) and `CLOSE` (approved CLOSEs to set Done in Linear by hand), each with one line saying what is needed, in one order: WARNING first, then what holds a team (PROPOSAL, STUCK, NEEDS YOU, GO), then the rest, oldest wait first. Every item carries `primary`, the one action HOME shows as its button. A FLIGHT that already has a queue row gets no second ALERT or STUCK row. The rail's HOME badge counts the whole list and takes the alert tone only when a WARNING row is in it; `GET /api/supervisor-summary` gains `todo`, the same count (`v` stays 1). The leak counter does not count the four new kinds as human steps (ATC-454).
