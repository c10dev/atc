### Changed
- A PR the SUPERVISOR approves (tier `user`, or ESCALATEd) now carries a "Behavior change" section: one text before/after diagram of what changes in atc's behaviour, or the line `Behavior change: none`. MCC INSPECTION flags a missing diagram, a diagram that contradicts the diff, and `none` on a PR that changes behaviour (P1). The PR drawer shows the diagram as a code block (ATC-360).
