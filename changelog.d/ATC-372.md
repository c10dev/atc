### Added
- A FLIGHT whose screen or DUTY-chat release declares a K3 effect (`K3[<label>]: <control> | files: <paths>` in `## K effects`) is launched on a fresh AIRCRAFT with `--settings` carrying per-FLIGHT `autoMode.allow` entries built by the server from that declaration, so the declared change does not stop on the classifier. Attested releases never build entries; the launch record carries the release id and the exact entries (ATC-372, K3).
