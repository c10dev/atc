### Added
- DUTY REVIEW: 서버가 DUTY 턴을 스스로 시작한다. 정해진 간격(4시간)이나 트리거(놀고 있는 AIRCRAFT가 Todo를 두고 20분, leak이 60분 넘게 열림)가 서면 DUTY가 착륙 대기열·DISPATCH 계획·leak·알림을 읽고, 채팅에 한국어 요약을 남기고, 고칠 일을 근거와 함께 ATC 이슈로 Backlog에 제안한다. Todo로 올리지 않고(점검 턴에서는 서버가 거절한다) 열린 이슈가 이미 다루는 일은 다시 제안하지 않는다. 스위치는 설정 → OPERATIONS → DUTY REVIEW 하나, 기본 켜짐, SUPERVISOR만 바꾼다. 점검·제안·발권된 제안·버려진 제안을 하루 단위로 센다(`GET /api/duty/review`, 설정 창에 표시) (ATC-396).
- `duty linear create --blocked-by ATC-n`(여러 번 가능): 새 이슈가 이미 받아들여진 FLIGHT 뒤에서 기다린다.
