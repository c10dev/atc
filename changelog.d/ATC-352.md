### Added
- Control sessions file a human decision as one SUPERVISOR QUEUE card (kind `DECISION`) with `atcctl decision file <role> <key> --ask … --option …` and end the turn instead of waiting `blocked` (ATC-352, [docs/occ.md](docs/occ.md) "DECISION cards").
  - Same role and key is filed once. The SUPERVISOR answers on the card (screen only); the answer reaches the session in its next tick brief (`decision-answered`; for DUTY, the end of `duty brief`), and `decision ack` marks it read.
  - The TOWER, OCC, MCC, CROSSCHECK and DUTY rules say: never end a turn waiting for the SUPERVISOR, a card only for a K1–K3 decision, every other decision goes ahead on a stated default, asks that are not the SUPERVISOR's go to DUTY or DISPATCH.
  - `atcctl decision default <role> <key> --what … --chose …` records such a default in the FLIGHT RECORDER (no card). Only TOWER and OCC run `decision` commands; the MCC, CROSSCHECK and DUTY guards are unchanged.

### Changed
- A control session whose job is `blocked` is a rule breach: an ALERTS WARNING `RULE BREACH` (`health|CONTROL-BLOCKED|<id>`) instead of a NEEDS YOU row (ATC-352, [docs/alerting.md](docs/alerting.md)).
