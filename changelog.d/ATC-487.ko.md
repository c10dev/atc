### 추가
- RELEASE 화면이 손으로 올린 Backlog 이슈를 접힌 `PARKED` 절(기본 닫힘, 머리에 수)에 보인다: 후보 팀의 이슈 가운데 막는 이슈가 없고 상위 이슈·끝난 것·atc 제안이 아닌 것. 줄마다 key·제목·우선순위·나이·올린 쪽·K 줄·`Sequence:` 줄과 READY 줄과 같은 **발권** 단추가 있다(클릭 한 번으로 Backlog를 Todo로 옮기고 화면 발권을 적는다. Origin 검사, 우선순위 0 거절, K3 길이 같다). 이 절은 스스로 발권하거나 옮기지 않는다. 스위치 `releaseParked`(설정 창, 기본 켜짐)를 끄면 절이 사라지고 `POST /api/releases/fire`가 이런 이슈를 다시 거절한다. 오작동 카운터는 PARKED에서 발권한 이슈가 24시간 안에 Canceled·Duplicate가 된 수를 7일 동안 센다([docs/dispatch.ko.md](docs/dispatch.ko.md)). 작업 지시서를 올린 세션은 이슈를 Backlog에 두고 스스로 Todo로 옮기지 않는다.
