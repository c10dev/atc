### Added
- DUTY cards and the QUEUE row (DUTY D3, ATC-230, [docs/duty.md](docs/duty.md) "D3 as built"): a card DUTY asks for with `atcctl duty card` now shows in the DUTY drawer, in order with its text, as the live SUPERVISOR QUEUE row. It greys out with `처리됨` or `큐에서 빠짐` when the row is done or leaves the queue.
  - Inline buttons are the screen's own calls to the existing routes, with one confirm: FLEET PLAN 동의·반대 (SHADOW) or 승인(실행)·거절 (APPROVAL), and UPDATE. PROPOSAL, SCHEDULE, HUMAN CHECK, LANDING (the PR drawer), NEEDS YOU and GO are links. No approve, reject, merge or send route is callable from DUTY or `atcctl`; GO stays a link.
  - A refused card request (key not in the queue) writes nothing and DUTY reports the reason in text. `note` and `charter` drafts show as muted read-only cards.
  - A folded `QUEUE nn · …` row above the chat expands to the whole queue with the same buttons and links. It reads `/api/supervisor/queue` when the screen's snapshot changes; no new polling.
  - DUTY's `atcctl` now talks to the server that started it (`ATC_URL`), so a test server's DUTY no longer reaches 7700.
  - Manual: `duty/CLAUDE.md` · `CLAUDE.en.md` "When to ask for a card". Guide page "DUTY 채팅" updated.
