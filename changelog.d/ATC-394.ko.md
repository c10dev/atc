### 추가
- 자동 revert 레인을 flake 방어와 함께 처음부터 켠다(ATC-394, ATC-351 PR 404를 현재 `main` 위로 다시 만듦. [docs/autonomy.ko.md](docs/autonomy.ko.md) "C4 구현 결과", [docs/mcc.md](docs/mcc.md), [docs/occ.ko.md](docs/occ.ko.md) 9.7).
  - MCC나 AUTOLAND가 머지한 PR이 `main`을 빨갛게 만들면 atc가 그 머지의 revert PR을 열고, 다음 초록 head가 멈춤을 푼다. 레인은 **처음부터 켜져 있다**(shadow 없음). SUPERVISOR의 `off` 스위치(설정 창 LANDING의 "AUTO REVERT")는 그대로 있다.
  - 되돌리기 전에 실패한 GitHub Actions run을 같은 head에서 한 번 다시 돌린다. 다시 돌려 초록이면 flake라서 아무것도 되돌리지 않고 breaker에도 세지 않는다. 다시 빨갛고 되돌릴 PR 자신의 head가 초록이었을 때만 되돌린다. 다시 돌릴 수 없는 체크, 끝나지 않는 재실행, PR 자신의 head가 초록이 아니었던 경우는 `hold` 줄이다.
  - revert와 잡은 flake는 날짜별로 기록하고 AUTO REVERT 줄 아래에 센다. 되돌린 PR이 24시간 안에 그대로 다시 머지되면(revert의 revert, 같은 파일) misfire로 센다.
  - breaker는 그대로다: 1시간 안에 새 빨간 head가 둘이면 레인이 멈추고 AUTOLAND `merge`는 `update`로, MCC 착륙은 끔으로 내려간다. 사람의 머지, 마이그레이션(K1)·`user` 등급(K3) PR은 자동으로 되돌리지 않는다.
