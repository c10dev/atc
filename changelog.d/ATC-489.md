### Changed
- REVIEW (the landing review session) can now read a large PR's whole diff: `GET /api/landing/review/:repo/:pr?part=<n>` and `atcctl landing review <owner/name>#<PR> --part <n>` return the n-th part (each at most 80,000 characters, cut at a file or line boundary; the packet says `part`, `parts` and `partFiles`). `diffTruncated` is now true only for files with no patch (named in `unreadFiles`), so a large PR no longer gets a P1 that no FIX can answer. `review/CLAUDE.md` tells REVIEW to read every part before a verdict and to write which parts it read (ATC-489).
